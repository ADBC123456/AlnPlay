# 播放页布局与触摸区域

日期：2026-09-08

## 实现位置

- `lib/widgets/player_chrome.dart`：独立控制层。顶部返回、标题、音轨与更多；右侧锁定；底部时间、粉色进度条，播放/下一集/弹幕开关与设置，字幕/选集/倍速/实际分辨率/全屏。没有中央播放或暂停图标，也没有弹幕输入、点赞、评论、投币、充电、分享或截帧入口。
- 控制层以 180 ms 淡入淡出，支持关闭动画；空白渐变不参与命中，隐藏控件不参与触摸和焦点。窄屏与大字号自动换行，按钮至少 48 dp；解锁按钮最后绘制，避免被底栏遮挡。
- `lib/widgets/player_gesture_surface.dart`：`seekDirection` 只允许左右各 25% 双击 ±10 秒；中间 50% 不 seek。首次单击仍立即响应；长按临时二倍速与释放恢复保留。
- `lib/screens/player_screen.dart`：时间轴继续独立刷新，原生视频 SurfaceView 与解码/HDR/DV 路径不变。分辨率按钮打开实际媒体信息，不改变播放质量。
- 播放页选集从统一库读取当前季，优先同来源版本，仅在选择后解析 URL；无统一库身份时读取已有本机/Jellyfin 同目录列表。选择后更新最近播放剧集，沿用当前引擎。下一集按自然集序前进，无下一集时提示。
- 切换期间隔离旧媒体事件，原生 open 成功后恢复新状态。MPV reload 内先停止旧流，再准备新集字幕、音轨偏好与章节，异常时解除准备标志。
- 弹幕设置面板实时调整字号、不透明度、显示区域，关闭时保存已有设置存储。
