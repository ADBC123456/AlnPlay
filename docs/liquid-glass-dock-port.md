| 内容 | 移植决策 |
| --- | --- |
| 材质分层、低透明填充、渐隐高光 | 采用，主题和文字沿用 AlnPlay |
| 连续圆角 | 使用 Flutter 3.44 已有的 `ClipRSuperellipse` / `RSuperellipse`，无需 FFI 或每帧 180 点采样 |
| 全局 `n=4` 超椭圆方程 | 不直接用于长条 Dock；长宽比放大后会改变原胶囊比例，采用局部连续圆角 |
| 原生 Compose / AGSL、Web DOM / SVG 滤镜 | 不能直接引入 Flutter；材质以 Dart painter + Flutter fragment shader 独立实现 |
| `ShaderMask` 包裹第二个 `BackdropFilter` | 不直接复制：遮罩的离屏图层会改变 backdrop 采样根，空 child 也不等价于可混合的模糊图像 |
| “只模糊一次”与“双层模糊” | 原文表述不一致；这里明确为每个玻璃表面一个 backdrop 过滤器，内部原生模糊加边缘采样，不对每个按钮分别模糊 |
| 弹簧、速度传递、手势归属 | 可移植为 `SpringSimulation` + 横向手势识别器 |
| Android API 31/33 分级 | 不照搬；Flutter 按 `ImageFilter.isShaderFilterSupported` 判断实际后端 |

Web 项目用 SVG 位移滤镜分别取 RGB，再合成边缘折射；默认色散参数为 1.2，
其折射强度会受控件尺寸限制。这里参考方法并独立编写 GLSL，未拷贝该项目
TypeScript、SVG、贴图或素材。浏览器的 UA 分流、Worker 和纹理缓存不适用于此处。

## 材质与参数

| 参数 | 当前实现 |
| --- | --- |
| 整组最大宽度 | 560 逻辑像素，保持原值 |
| 导航高度 | 64，大字增高至最多 84，保持原算法 |
| 独立搜索 | 64 × 64，间隔 12，保持原值 |
| 选中层边距 | 5，保持原值 |
| Dock 本体与搜索 | 保持原有 sigma 18 均匀高斯模糊，不使用色散 shader |
| 滑块中心 | sigma 0.6 轻微散射，平面区不做折射或色散 |
| 滑块倒角 | 约 12 像素区域，指数 1.6；边缘额外柔化最多 sigma 0.65 |
| 增强采样 | 每个通道 5 点归一化软边采样，中心只取一次背景 |
| 折射 | Snell 近似，入射角随倒角坡度变化；有效厚度 6，按住/拖动增至 10 |
| 色散 | 仅滑块；有效 IOR 红 1.435、绿 1.46、蓝 1.485，沿同一法线蓝偏移最大、红最小，差值随折射自然增长 |
| 深色底色 | 近黑 18%，叠加少量白色表面反射 |
| 浅色底色 | 白色 12%，让背景透出 |
| 选中层 | 深色白 6% / 浅色白 14%，取代原先 97–99% 不透明遮盖；独立实时背景滤镜 |
| 边线 / 顶部反射 | 1 / 1.2 逻辑像素，顶部约 50% 白色，两端渐隐 |
| 弹簧 | mass 1、stiffness 420、dampingRatio 0.85 |
| 按住 / 拖动 | 120 ms，透镜横向放大 12%、纵向放大 22%；经过两项之间时额外横向拉伸最多 4%，松手恢复 |
| 跟手 / 松手 | 位移系数 0.9；速度参与落点预测与弹簧初速度 |

色散使用真实背景颜色。背景是纯色时不制造彩虹，图标与文字在滤镜之上正常绘制。
最终遵循用户明确区分的两层材质：本体保持高斯模糊，滑块才使用通透的薄透镜效果。
不照搬本地文档的 sigma 6→24 和 0.95 按压缩小推荐值。透镜光学与外壳分别绘制；
只裁剪各自玻璃背景，不裁剪外层交互 Stack，因此透镜可以放大超出外壳而不改变
导航/搜索的尺寸、间距或触控区。
本体模糊层按当前滑块轮廓留出取景区域，使滑块向内折射时读取原始页面，避免把
已经 sigma 18 模糊过的背景再次折射。留空形状和滑块共用缩放公式，随拖动重裁剪。
高光位置跟随触点，底部有轻微内暗边，阴影随按压变化；没有加入设备姿态传感器。
IOR 数值是克制视觉效果的近似参数，不代表精确的材料光谱或完整球面像差光线追踪。
旧实现的文字截图 atlas、重采样文字和不透明遮盖层已移除，不再存在重复字形或
异步截图与主题/尺寸不同步的问题。shader 的光学距离场采用胶囊近似，最终轮廓
由 Flutter 连续圆角裁剪，倒角处不是精确的玻璃光线追踪。

## 兼容与性能边界

- Impeller：仅滑块使用原生 sigma 0.6 后接实时背景 shader；本体与搜索保留 sigma 18。
- Skia 或 shader 加载失败：本体高斯模糊、滑块轻微模糊、连续圆角、高光和弹簧仍工作；
  不宣称具有真实背景色散，也不以彩虹边框冒充。
- 高对比度：关闭背景滤镜，使用实色材质和明确轮廓。
- 减少动态效果：不播放弹簧、按压缩放和拉伸；点击仍立即定位。
- 仅滑块持有 shader；不同 Dock 实例只共享编译后的 program。固定三个小面积
  滤镜，不按导航按钮数量增加。
- shader 的输入纹理覆盖场景，不能把纹理尺寸误当成滑块尺寸。自定义 render object
  在 paint 阶段提交变换后的屏幕坐标和视口尺寸，使折射/色散贴合正在移动的轮廓。
  当前集成以根页面、完整视口背景为采样环境，不能直接套用于任意离屏小画布。
- 中心平坦区域直接采样，15 次 RGB 软边采样只进入边缘区；没有逐帧截图或 CPU 回读。
- 拖动只更新 transforms / painter；标签内容不随每帧重新布局。静止时无持续动画。
- 横向识别器在 gesture arena 中竞争，取消不提交选项；后台切换立即清理交互状态。
  父组件确认新的选择不会重新启动弹簧并丢失松手速度；回归测试比较受控/未受控的轨迹。
- 此组件用于 Flutter 首页。不能读取原生 PlatformView 的 HDR 视频像素，
  不适用于对 Media3/AetherEngine 视频做背景模糊。

## 验证

WSL Ubuntu 26.04，Flutter 3.44.7 / Dart 3.12.2。

- `dart analyze lib test`：无问题。
- 普通后端：`flutter test --no-pub test/liquid_glass_dock_test.dart test/liquid_glass_optics_test.dart test/widget_test.dart test/library_home_layout_test.dart`，30 项通过。
- Impeller：同一 Dock / optics 测试加本地截图 harness，14 项通过；
  截图 harness 为 `build/dock/preview_test.dart`，不进入发布包。
- Dock、根导航、首页布局回归覆盖本体高斯模糊、点击、搜索返回、320–1194 宽度、深浅主题、
  1–3 倍字体、拖动取消、外部选择、动画打断、后台恢复、高对比度与减少动态效果。
- shader 像素测试验证：蓝/绿/红位移顺序、灰阶背景的边缘 RGB 分离、中心不染色、纯色不生彩虹、
  无透明采样缝；同时覆盖 Skia runtime shader 编译及 Impeller 渲染。
- Impeller 测试环境确认 `ImageFilter.isShaderFilterSupported == true`；
  375 / 834 宽度深浅主题组件截图在 `build/dock/`。
- 真机 Android / iPad 的光学强度、GPU 帧时间与高刷手感仍待校准；测试环境渲染
  和像素检查不能替代实际设备性能验证。
